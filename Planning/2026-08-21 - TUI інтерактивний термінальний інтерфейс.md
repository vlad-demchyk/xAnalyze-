# 2026-08-21 - TUI: інтерактивний термінальний інтерфейс

## Проблема

Коли користувач пише просто `xanalyze` без аргументів, нічого корисного не відбувається.
Потрібен інтерактивний термінальний інтерфейс (TUI) де можна:
- запускати сканування, аудит, fullscan
- вибирати ціль і параметри
- переглядати результати
- дивитися налаштування
- переглядати попередні звіти
- оновлювати програму

## Контекст

- Бібліотека: `textual` (обрано користувачем)
- CLI вже має всі команди; TUI є обгорткою над ними
- `app_entry.py` зараз запускає GUI або CLI залежно від `sys.argv[0]`
- Потрібно: якщо `xanalyze` без підкоманди → TUI

## Кроки

1. `pip install textual` + оновити requirements.txt
2. Створити `tui/` модуль:
   - `app.py` — головний Textual App з навігацією між екранами
   - `screens/main.py` — головне меню
   - `screens/scan.py` — форма сканування
   - `screens/audit.py` — форма аудиту
   - `screens/results.py` — таблиця результатів
   - `screens/settings.py` — перегляд налаштувань
   - `screens/reports.py` — список звітів
3. Змінити `app_entry.py`: якщо `xanalyze` без аргументів → TUI
4. Змінити `cli.py`: `main()` без підкоманди → TUI (для dev-запуску)
5. Оновити README
6. Тести
