# XAnalyze (`ai-content-scanner`) - правила репозиторія

Глобальний протокол - `~/.claude/CLAUDE.md` і канон сховища. **Тут лише те, що з них не
виводиться:** гілки, команди, архітектурні інваріанти цього коду. Протокол Second Brain у цьому
файлі не переказується: переказ дрейфує від канону, і саме так застарів `xformat-backend/CLAUDE.md`.

Стиль текстів: без довгого тире.

## Прив'язка до сховища

- Папка проєкту: `Projects/XAnalyze/` - канбан `STATE.md`, етапи `Roadmap.md`, `Problems.md`,
  `Planning/`, `Архів/`, `TODO.md`, `manual-todo.md`, `RESEARCH/`, `Devs/`, `Design/`.
- **Плани живуть у сховищі, не в репозиторії.** Тека `Planning/` у корені репо була помилкою
  (виправлено 2026-08-25): такий план невидимий для канбану і `vault-lint`, тож задача тихо
  отримує другого власника. Не створюй її знову.
- Файла стану в репо немає, на відміну від `xformat-backend`. Стан живе в канбані сховища.
- `Devs/` - жива документація коду, дрейфує від коду: перед довірою застосуй `devs-audit`.

## Запуск і перевірки

```bash
source venv/bin/activate          # venv/ і venv-py39-old/ у .gitignore
pip install -r requirements.txt

python main.py                    # десктоп (Qt)
python cli.py fullscan <ціль>     # headless
python cli.py                     # без підкоманди відкриває TUI (textual)

python -m pytest tests/           # 79 тестових файлів, окремого конфігу немає
```

## Архітектурні інваріанти

Повний опис - `Projects/XAnalyze/Devs/ARCHITECTURE.md`. Те, що ламається найчастіше:

- **Один факт має одного власника.** Найдорожчий клас дефектів тут, і **жоден із них не падав**:
  вікно тримало копії стану, якого ніхто не заповнював, через що аудит теки слав
  `https:///Users/...` у краулер і звітував порожній результат як чистий. Стан прогону читається
  через властивості **без сеттера**, тому спроба записати стару копію падає, а не розходиться.
- **Три точки входу, одне ядро.** `main.py` тонкий навмисно, `cli.py` не імпортує GUI-модулі на
  рівні файлу, `tui/` - обгортка над CLI, `app_entry.py` лише для зібраного бандла.
- **Що куди не має знати:** `detectors/*` не імпортують веб- чи репо-специфічного;
  `ui/tokens.py` парсить дизайн-систему, `ui/theme.py` малює нею; `report/*` не імпортує
  `i18n.translations` - у звіту власний словник у `report/template.py`.
